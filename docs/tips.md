# 💡 使用技巧

## 如何让 AI 读空气？(建议开启)

1. 在插件配置中开启 `read_air` 功能
2. 在人格设置中添加提示，例如：
   ```
   当群聊中出现以下情况时，请不要回复：
   1. 群友在讨论专业话题，而你无法提供有价值的见解
   2. 群内正在进行命令操作，不需要你的干扰
   3. 当话题与你无关，或者你的回复可能会打断当前的对话流
   ```
3. AI 会根据你设置的提示自动判断何时应该回复，何时保持沉默

## 设置黑名单关键词

为避免不必要的回复，可以设置黑名单关键词，AI不会响应包含这些关键词的消息。
比如，设置黑名单关键词为`/`，或者你的命令前缀，这样在群聊中使用命令时，AI就不会响应了，可以有效避免使用命令时因为触发了AI回复而导致需要等待AI回复完才会执行命令。

## 回复引用错位怎么办？

AstrBot 开启「回复时引用发送人消息」后，总是引用**触发回复的那条消息**。但大模型能看到最近的聊天记录，它的回复可能针对的是之前的某条消息（比如之前发的图片），于是看起来引用错了。

插件的 `smart_quote`（模型自主选择引用的消息，默认开启）会给聊天记录中的消息编号，模型可以在回复开头写 `[引用:编号]` 来引用它真正回应的那条消息，插件会移除这个标记并插入对应的引用；没有写时仍然引用触发回复的消息。

- 仅在 AstrBot 开启了「回复时引用发送人消息」时生效，不会给原本不引用的回复加上引用
- 需要 AstrBot v4.19.3 及以上
- 开启流式输出时不生效
- 如果开启了「回复时 @ 发送人」，会改为 @ 被引用消息的发送者
